Script CSV Format Instructions

Upload a CSV file containing your expected script text for each audio file.

CSV Format (with header):

filename,script_text
audio1.wav,"This is the expected text for audio 1"
audio2.wav,"Line 1 of script
Line 2 of script
Line 3 of script"

CSV Format (without header):

audio1.wav,"This is the expected text for audio 1"
audio2.wav,"This is the expected text for audio 2"
audio3,"This can also work without the .wav extension"
  • •
    Header row is optional - the parser will auto-detect it
  • •
    Multi-line scripts are supported - wrap them in double quotes
  • •
    Filenames must match the audio files you upload (including extensions)
  • •
    Empty rows are automatically skipped
  • •
    Both filename and script text are required for each row
  • •
    Scripts can be uploaded before or after audio files
